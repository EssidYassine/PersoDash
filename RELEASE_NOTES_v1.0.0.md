## PersoDash 1.0.0 — première version publique 🎉

Ta boîte Gmail sur ton PC, avec un détecteur de phishing intégré.

### Nouveautés
- 🛡️ **Score de risque** sur chaque email : SPF / DKIM / DMARC, domaines sosies, liens trompeurs, liens vers une IP, expéditeur usurpé, réponses détournées.
- 🔍 **Analyse des pièces jointes** : vrai type de fichier, doubles extensions, réputation VirusTotal par empreinte (le fichier n'est jamais envoyé).
- 📥 Client Gmail complet : dossiers, recherche, répondre, transférer, archiver, libellés, aperçu des pièces jointes.
- 📅 Agenda et tâches intégrés, email → tâche en une touche.
- 🔔 Notifications Windows, icône près de l'horloge.
- 🔐 Mot de passe dans le coffre chiffré de Windows, aucun serveur intermédiaire.
- 🎨 Thème clair / sombre, mode démo pour essayer sans compte.

### Installation
Télécharge **PersoDash-Setup-1.0.0.exe** ci-dessous et lance-le (pas besoin de droits administrateur). Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*.
